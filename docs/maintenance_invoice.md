## What "Maintenance" Covers

In simple terms, this fee keeps your system **running safely, smoothly, and up to date**. Every month, this includes:

- **Keeping the system online** — monitoring the website/app so it stays up and available for your staff and guests.
- **Fixing bugs** — if something breaks or behaves incorrectly, it gets fixed.
- **Security updates** — applying important updates to keep your data and your guests' data safe from hackers or leaks.
- **Server upkeep** — making sure the server (the computer that runs your system) is healthy, has enough space, and is performing well.
- **Small technical adjustments** — minor tweaks needed to keep existing features working correctly (not new features — see below).
- **Support** — answering questions and helping resolve issues that come up while using the system.
- **Backups** — making sure your data is regularly backed up so nothing is lost.

## What Is NOT Included (Important)

**New features are not part of maintenance.**

This fee only covers keeping the *current* system healthy and working. It does **not** include:

- Building new features or new pages
- Major changes to how the system looks or works
- Adding new tools, reports, or integrations

Any new feature or major change will be quoted and priced **separately**, once we discuss what you need.

## Quarterly Server Report

Every 3 months, you will receive a simple report on your server's health — covering things like uptime, performance, and any issues found and fixed. This helps you stay informed about your system without needing to understand the technical details.
